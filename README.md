
## About the Project

This is a web-based automotive workshop management system designed to streamline daily operations, manage customer information, track vehicles, control inventory, schedule appointments, and monitor financial records.

## Technologies Used

- C#
- ASP.NET Core MVC
- ASP.NET Core Web API
- .NET 10
- SQL Server
- Dapper
- HTML
- CSS
- JavaScript
- Bootstrap
  

## Main Features

### User Management
- User registration and administration.
- Role-based access control.
- User authentication.

### Customer and Vehicle Management
- Customer information management.
- Vehicle registration and updates.
- Vehicle status tracking.

### Inventory Management
- Product registration and management.
- Inventory control.
- Stock monitoring.

### Appointment Management
- Appointment scheduling.
- Appointment status management.
- Workshop availability management.

### Financial Management
- Income and expense tracking.
- Financial record management.
- Payment status monitoring.

### Reports and Analytics
- Financial reports.
- Customer reports.
- Appointment reports.
- Inventory reports.
- Vehicle income reports.
- Visualization of reports using charts.

## System Architecture

- **Frontend:** ASP.NET Core MVC with Razor Views.
- **Backend:** ASP.NET Core Web API.
- **Database:** Microsoft SQL Server.
- **Data Access:** Dapper.

## User Roles

- **Administrator:** Full system administration.
- **Manager:** Workshop operations and management.
- **Mechanic:** Access to assigned workshop operations.
